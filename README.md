# Ladd_r preview

Interactive front-end prototype for **Ladd_r — Discover what’s missing.**

This repository is the iPhone-friendly GitHub Pages preview. It uses browser-local storage and demo data until production authentication, database, AI, billing, job-search, and email services are connected.

## Preview features
- Responsive landing page
- Free / Core ($7) / Grow ($12) pricing
- Weekly job matches
- Application tracker
- Résumé bank and demo credit logic
- Interview-prep wizard
- Grow salary-path view
- Experience Diary
- Mobile navigation

No placement, salary, interview, or promotion outcomes are guaranteed.
